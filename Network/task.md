**2. Попробуйте изменить IP-адрес**
с помощью - ip addr 

**3. Попробуйте добавить несколько IP-адресов на сетевую карту**
ip addr add 192.168.1.101/24 dev enp0s1 label enp0s1:1
ip addr add 192.168.1.102/24 dev enp0s1 label enp0s1:2

**4. Выведите список маршрутов**
ip route show

**5. Выведите ARP-таблицу**
ip neigh show

**6. Что такое IP-адрес?**
Уникальный числовой идентификатор устройства в компьютерной сети, который позволяет находить и взаимодействовать с ним.

**7. Для чего нужны маршруты?**
Маршруты определяют путь, по которому сетевые пакеты достигают своего назначения, указывая через какие шлюзы и интерфейсы передавать трафик для разных сетей.

**8. Что за протокол ARP?**
Протокол разрешения адресов, который преобразует IP-адреса в MAC-адреса в локальной сети.

**9. Что такое DHCP?**
Протокол динамической конфигурации хостов, который автоматически назначает IP-адреса и другие сетевые параметры устройствам в сети.

**10. Что такое DNS?**
Система доменных имен, которая преобразует читаемые человеком доменные имена в соответствующие IP-адреса.

**11. Как называется один из протоколов синхронизации времени?**
NTP (Network Time Protocol)

**12. Что такое широковещательный запрос, зачем он нужен?**
Широковещательный запрос отправляется всем устройствам в локальной сети. Он нужен для обнаружения служб, ARP-запросов, DHCP и других сетевых операций.

**13. Какой адрес является широковещательным?**
255.255.255.255 (для всей сети) или адрес, где все биты хостовой части равны 1 (например, 192.168.1.255 для сети 192.168.1.0/24)

**14. Какие ещё параметры можно задать сетевой карте?**
MTU (максимальный размер пакета), MAC-адрес, скорость и режим дуплекса, состояние (включить/выключить), VLAN-настройки.

**15. Что такое маска подсети? Зачем она нужна?**
Маска подсети определяет, какая часть IP-адреса относится к сети, а какая к конкретному устройству (хосту). Она нужна для разделения больших сетей на подсети, эффективной маршрутизации, контроля широковещательного трафика и обеспечения безопасности через сегментацию сети.

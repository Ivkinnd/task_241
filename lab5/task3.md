# Журнальчики

1.Посмотрите журналы ssh  
   Команда `journalctl -u sshd` показывает все записи журнала, связанные с работой SSH-сервера.

2.Выведите журналы в реальном времени  
   Для вывода логов в режиме реального времени используется команда `journalctl -f`, которая обновляет отображение по мере появления новых записей.

3.Выведите лог в реальном времени для службы sshd  
   Команда `journalctl -f -u sshd` отображает логи SSH-сервиса в реальном времени с фильтрацией только для этой службы.

4.Можно ли без команды journalctl прочитать логи systemd?  
   Да, логи systemd хранятся в директории `/var/log/journal/` в бинарном формате, однако для удобного просмотра рекомендуется использовать утилиту journalctl.

5.Сколько будет 2-2?  
   Результат вычисления `2 - 2` равен 0. В терминале это можно проверить с помощью команды `expr 2 - 2`.
